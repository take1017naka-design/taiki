# 薬品辞書

入力された薬品について調べた内容をまとめる辞書。商品名で入力された場合は一般名も併記し、
剤形や用途など「使い方」による分類がある薬品はその区分ごとに整理する。

## ラキソベロン(Laxoberon)

### 基本情報
| 項目 | 内容 |
|---|---|
| 商品名 | ラキソベロン |
| 一般名 | ピコスルファートナトリウム水和物(Sodium Picosulfate Hydrate) |
| 薬効分類 | 大腸刺激性下剤(ジフェニールメタン系) |
| 作用機序 | 大腸内細菌の酵素により加水分解され活性代謝物(ジフェノール体)となり、大腸粘膜を直接刺激して蠕動運動を促進。あわせて大腸での水分吸収を抑制し便を軟化させる |
| 適応 | 各種便秘症、術前・検査前(注腸検査・大腸内視鏡検査など)の腸管内容物の排除 |

### 使い方(剤形)による分類

| 剤形 | 代表製品 | 用法・用量の目安 | 特徴 |
|---|---|---|---|
| 内用液(滴下タイプ) | ラキソベロン内用液0.75% | 成人:1日1回10~15滴(小児は年齢・体重により調整、通常1日1回2~7滴程度)、就寝前に服用 | 1滴単位で微調整でき、小児・高齢者・症状に応じた細かい用量調節がしやすい |
| 錠剤 | ラキソベロン錠2.5mg | 成人:1日1回2~3錠、就寝前に服用 | 携帯・保管がしやすいが用量調整の幅は内用液より粗い |

※ジェネリック医薬品は「ピコスルファートナトリウム内用液0.75%『○○』」のように一般名+屋号で流通している。

### 用法上の注意点
- 効果発現まで8〜12時間程度かかるため、就寝前投与→翌朝排便を狙う使い方が基本(朝や日中の頓用には不向き)。
- 検査前処置として使う場合は、他の腸管洗浄剤(ニフレック等)と併用・前投与するレジメンがあり、単独使用時と用量・タイミングが異なる。
- 長期・高用量の連用で耐性(効きにくくなる)や電解質異常(低カリウム血症など)のリスクがあるため、慢性便秘での連用は最小有効量に留める。

### 主な副作用
腹痛、下痢、悪心・嘔吐、(長期大量使用時の)電解質異常・脱水

### 併用注意
他の刺激性下剤(センノシド、ビサコジルなど)との併用で効果が増強し、腹痛・下痢が強く出ることがある。
