# 薬品辞書

入力された薬品について調べた内容をまとめる辞書。商品名で入力された場合は一般名も併記し、
剤形や用途など「使い方」による分類がある薬品はその区分ごとに整理する。
各エントリには「一般名」と「処方箋への書式(商品名処方/一般名処方それぞれの書き方)」を必ず記載する。

## ラキソベロン(Laxoberon)

### 基本情報
| 項目 | 内容 |
|---|---|
| 商品名 | ラキソベロン |
| 一般名 | ピコスルファートナトリウム水和物(Sodium Picosulfate Hydrate) |
| 薬効分類 | 大腸刺激性下剤(ジフェニールメタン系) |
| 作用機序 | 大腸内細菌の酵素により加水分解され活性代謝物(ジフェノール体)となり、大腸粘膜を直接刺激して蠕動運動を促進。あわせて大腸での水分吸収を抑制し便を軟化させる |
| 適応 | 各種便秘症、術前・検査前(注腸検査・大腸内視鏡検査など)の腸管内容物の排除 |

### 使い方(剤形)による分類

| 剤形 | 代表製品 | 用法・用量の目安 | 特徴 |
|---|---|---|---|
| 内用液(滴下タイプ) | ラキソベロン内用液0.75% | 成人:1日1回10~15滴(小児は年齢・体重により調整、通常1日1回2~7滴程度)、就寝前に服用 | 1滴単位で微調整でき、小児・高齢者・症状に応じた細かい用量調節がしやすい |
| 錠剤 | ラキソベロン錠2.5mg | 成人:1日1回2~3錠、就寝前に服用 | 携帯・保管がしやすいが用量調整の幅は内用液より粗い |

※ジェネリック医薬品は「ピコスルファートナトリウム内用液0.75%『○○』」のように一般名+屋号で流通している。

### 一般名・処方箋への書式
| 書式 | 記載例 |
|---|---|
| 商品名処方 | ラキソベロン内用液0.75% |
| 一般名処方 | ピコスルファートナトリウム内用液0.75% |

```
Rp)
ピコスルファートナトリウム内用液0.75%     1本

用法:1日1回10~15滴、就寝前に経口投与する
```

### 用法上の注意点
- 効果発現まで8〜12時間程度かかるため、就寝前投与→翌朝排便を狙う使い方が基本(朝や日中の頓用には不向き)。
- 検査前処置として使う場合は、他の腸管洗浄剤(ニフレック等)と併用・前投与するレジメンがあり、単独使用時と用量・タイミングが異なる。
- 長期・高用量の連用で耐性(効きにくくなる)や電解質異常(低カリウム血症など)のリスクがあるため、慢性便秘での連用は最小有効量に留める。
- 添付文書上は絶対的な上限滴数の規定はなく「年齢、症状により適宜増減」とされる。実臨床では成人で概ね15~30滴程度に留めることが多い。

### 主な副作用
腹痛、下痢、悪心・嘔吐、(長期大量使用時の)電解質異常・脱水

### 併用注意
他の刺激性下剤(センノシド、ビサコジルなど)との併用で効果が増強し、腹痛・下痢が強く出ることがある。

## リンデロン-VG軟膏(Rinderon-VG Ointment)

### 基本情報
| 項目 | 内容 |
|---|---|
| 商品名 | リンデロン-VG軟膏0.12%(クリーム・ローションもあり) |
| 一般名 | ベタメタゾン吉草酸エステル・ゲンタマイシン硫酸塩配合剤(Betamethasone Valerate/Gentamicin Sulfate) |
| 薬効分類 | 合成副腎皮質ホルモン(ステロイド:strongランク)+ アミノグリコシド系抗生物質の配合外用剤 |
| 適応 | 湿疹・皮膚炎群などステロイド外用の適応疾患のうち、細菌の二次感染を伴う、または伴うおそれがある場合 |

### 使い方(剤形)による分類
| 剤形 | 基剤の特徴 | 適した部位・状態 |
|---|---|---|
| 軟膏0.12% | 油脂性基剤、保湿・保護効果が高くべたつく | 乾燥・肥厚した皮疹、慢性の湿疹、亀裂・潰瘍面 |
| クリーム0.12% | のびが良くべたつきにくい | ジュクジュクした湿潤病変、脂漏部位 |
| ローション0.12% | 液状で塗り広げやすい | 頭皮など毛髪部位、広範囲への塗布 |

### 一般名・処方箋への書式
| 書式 | 記載例 |
|---|---|
| 商品名処方 | リンデロン-VG軟膏0.12% |
| 一般名処方 | ベタメタゾン吉草酸エステル・ゲンタマイシン硫酸塩配合軟膏0.12% |

```
Rp)
ベタメタゾン吉草酸エステル・ゲンタマイシン硫酸塩配合軟膏0.12%     5g

用法:1日2回(朝・入浴後)、右前腕の湿疹部に薄く塗布する
     顔面・陰部には使用しないこと
     7日分。症状軽快後は保湿剤またはステロイド単剤へ切替のため再受診
```

### 用法・用量、1回量・回数・上限
- 添付文書上は「1日1~数回、適量を患部に塗布する」とされ、明確な上限グラム数の規定はない。
- ステロイド外用薬共通のFTU(Finger Tip Unit)の考え方に準じて量を決める。
- 「上限」はグラム数ではなく使用期間で管理するのが基本。症状改善後は速やかに弱いランクのステロイド単剤や保湿剤へ切り替え、漫然と長期連用しない。
- 顔面・陰部・脇の下などの皮膚が薄い部位は、同じ強さでも短期間・少量にとどめる。
- 広範囲・長期間・密封療法(ODT)は経皮吸収増加によるステロイドの全身性副作用のリスクがあるため避ける。

### 禁忌・注意すべき病態
ウイルス性皮膚疾患(単純疱疹、水痘、帯状疱疹など)、真菌性皮膚疾患(白癬、カンジダ症など)、結核性皮膚疾患、鼓膜に穿孔のある方の外耳道への使用は禁忌。

### 主な副作用
皮膚萎縮、毛細血管拡張、酒さ様皮膚炎、多毛、色素沈着・脱失、接触皮膚炎/過敏症、(長期使用による)ゲンタマイシン耐性菌の出現、まれに全身性ステロイド副作用(乳幼児・広範囲長期使用時)

## カロナール(Calonal)

### 基本情報
| 項目 | 内容 |
|---|---|
| 商品名 | カロナール(錠・細粒。小児用坐剤はアンヒバ坐剤等の別ブランドで流通) |
| 一般名 | アセトアミノフェン(Acetaminophen) |
| 薬効分類 | 解熱鎮痛薬(非ピリン系) |
| 適応 | 各種発熱・疼痛(頭痛、腰痛、月経痛、抜歯後疼痛など) |

### 使い方(剤形)による分類
| 剤形 | 代表製品 | 特徴 |
|---|---|---|
| 錠剤 | カロナール錠200mg・300mg・500mg | 定時・頓用いずれにも使用 |
| 細粒 | カロナール細粒20%・50% | 小児や嚥下困難な患者向け |
| 坐剤 | アンヒバ坐剤・アルピニー坐剤(同一成分) | 乳幼児・嘔吐時など経口摂取できない場合 |

### 一般名・処方箋への書式
| 書式 | 記載例 |
|---|---|
| 商品名処方 | カロナール錠300mg |
| 一般名処方 | アセトアミノフェン錠300mg |

### 頓用時の処方箋記載例(一般名処方)
```
Rp)
アセトアミノフェン錠300mg          12錠

用法:発熱時・疼痛時に1回1~2錠(300~600mg)を頓用
     再度使用する場合は4~6時間以上あけること
     1日4回まで(1日総量4000mgを超えないこと)
     ○日分(頓用)
```

### 用法・用量、1回量・回数・上限
| 対象 | 1回量 | 最短間隔 | 1日上限 |
|---|---|---|---|
| 成人(体重50kg以上) | 300~1000mg | 4~6時間以上 | 4000mg |
| 成人(体重50kg未満)・小児 | 10~15mg/kg | 4~6時間以上 | 60mg/kgかつ4000mgを超えない |

### 注意点
- 頓用処方には「トリガー条件(発熱時・疼痛時等)」「最短間隔」「1日上限回数・上限量」の3点を必ず明記する。
- 市販の総合感冒薬にもアセトアミノフェンが含まれる製品が多く、重複服用による過量摂取に注意する。

### 主な副作用
まれに重篤な皮膚障害、肝機能障害、消化器症状(悪心・嘔吐)。過量摂取時は肝毒性のリスクが高い。
