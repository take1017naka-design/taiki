# 外用薬の処方指示について適切な指示の仕方

外用薬(軟膏・クリーム・ローション・貼付剤・点眼薬・点鼻薬・坐剤・含嗽剤など)は、内服薬と異なり
「どこに」「どのように」使うかが指示に含まれていないと、患者が自己判断で使用方法を誤りやすい。
処方・調剤・服薬指導の各場面で確認すべきポイントを剤形別にまとめる。

## 1. 外用薬指示に共通して必要な5要素

| 要素 | 内容 | 悪い例 | 良い例 |
|---|---|---|---|
| 部位 | 使用する体の部位を具体的に | 患部に | 右膝内側の湿疹部に |
| 回数・タイミング | 1日の使用回数と時間帯 | 適宜 | 1日2回(朝・入浴後) |
| 使用量 | 目安量(FTUなど)を明記 | 適量 | 1回1FTU(人差し指の先端から第一関節まで) |
| 使用方法 | 塗る・貼る・点す等の操作 | 使用する | 薄く塗り広げる/擦り込まない |
| 使用期間・終了条件 | いつまで続けるか | 定めない | 症状消失後3日で中止、再燃時は再受診 |

「患部に適量を塗布」だけの指示は、部位・量・回数のいずれも患者に委ねてしまうため避ける。

## 2. 剤形別のチェックポイント

### 軟膏・クリーム・ローション(外用ステロイド等)
- 部位を具体的に指定する(顔面/体幹/四肢で強さのランクを変える場合は特に重要)。
- 使用量は **FTU (Finger Tip Unit)** を用いると患者に伝わりやすい。
  - 1FTU ≒ 成人の手のひら2枚分の面積に塗布できる量。
- 「1日〇回」に加えて塗布のタイミング(入浴後・保湿剤の前後など)を指定する。
- 粘膜・眼周囲への使用可否を明記する。
- ステロイドの場合はランクダウンの予定(漸減スケジュール)があれば併記する。

### 貼付剤(湿布・経皮吸収型製剤)
- 貼り替え間隔(12時間ごと/24時間ごと/週2回など)を明記する。
- 同一部位への連続貼付を避けるためのローテーション部位を指示する。
- はがすタイミング(入浴前など)と、はがした後の休薬時間が必要な製剤(ニトログリセリンパッチ等)は明記する。
- 1回に使用してよい枚数の上限がある製剤は上限を明記する。

### 点眼薬・点鼻薬
- 1回の滴数(例:1回1滴)を明記する。点眼薬は「適量」ではなく滴数で指示する。
- 複数の点眼薬を併用する場合は、点眼間隔(5分以上あける)と順序(懸濁性点眼薬は最後)を指示する。
- 点眼後の圧迫(涙嚢部圧迫)や、コンタクトレンズ装着前後の使用可否を記載する。

### 坐剤・膣剤
- 挿入部位(肛門/膣)と体位、挿入の深さの目安を記載する。
- 発熱時頓用など、頓用の場合は再使用までの最短間隔と1日の上限回数を明記する。

### 含嗽剤(うがい薬)・口腔用薬
- 希釈が必要な製剤は希釈倍率を明記する(原液使用不可の場合は特に注意)。
- 使用後の飲食制限(30分は飲食を避ける等)があれば記載する。

## 3. 処方箋・薬袋への記載例

```
【例:外用ステロイド】
販売名:○○軟膏0.1%  10g
用法:1日2回(朝・入浴後)、両手背の湿疹部に1回1FTUを薄く塗布する
     顔面には使用しないこと。症状軽快後は保湿剤へ切り替え、2週間で再評価。

【例:貼付剤】
販売名:○○テープ  7枚
用法:1日1回、24時間ごとに貼り替える。同一部位への連続貼付は避け、
     胸部・上腕・背部をローテーションすること。

【例:点眼薬】
販売名:○○点眼液0.1%  5mL
用法:1回1滴、1日3回(起床時・昼・就寝前)、両眼に点眼する。
     他の点眼薬と併用する場合は5分以上間隔をあけること。
```

## 4. 調剤・服薬指導時の確認事項

- 「1日3回」など内服薬と同じ書式のみで、部位・量の記載が欠落していないか。
- 一包化の対象外である(外用薬は一包化しない)ことを処方・調剤システム上で確認する。
- 後発品変更により剤形(軟膏⇔クリームなど基剤)が変わる場合は、患者への説明を追加する。
- 妊婦・授乳婦・小児への適用可否、粘膜・目・口への使用制限を確認する。
- 保管方法(遮光・冷所保存など)に特記事項がある製剤は薬袋に明記する。

## 5. まとめ:指示文を書く際のセルフチェック

1. **部位**は具体的か(「患部」だけになっていないか)
2. **回数とタイミング**は明確か
3. **量**は数値・単位(FTU、滴数、枚数など)で示されているか
4. **使用方法**(塗る/貼る/点す等の操作方法・禁止事項)は書かれているか
5. **期間・中止基準**は示されているか

この5点を満たすことで、外用薬の誤使用・効果不十分・過量使用のリスクを減らすことができる。
