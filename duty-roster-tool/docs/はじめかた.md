# はじめかた（自分のパソコンで使う）

プログラムの知識がなくても使えるようにしてあります。
**最初の1回だけ準備**をして、あとは毎月ファイルをドラッグするだけです。

---

## 用意するもの

- Windows か Mac のパソコン
- **Python 3.10 以降**（無ければ下の手順で入れます）
- このツール一式（`duty-roster-tool` フォルダ）

---

## Windows の場合

### 1回だけの準備

1. **Python を入れる**（すでに入っていれば飛ばしてください）

   https://www.python.org/downloads/windows/ を開き、
   最新の「Windows installer (64-bit)」をダウンロードして実行します。

   > **重要**: インストール画面のいちばん下にある
   > **「Add python.exe to PATH」に必ずチェックを入れて**ください。
   > ここを忘れると、次の手順で「Python が見つかりません」と出ます。

2. `duty-roster-tool` フォルダを、書き込みできる場所に置きます
   （例: `ドキュメント\duty-roster-tool`）。
   ネットワークドライブ上だとうまく動かないことがあります。

3. `windows` フォルダの中の **「1_セットアップ.bat」をダブルクリック**します。

   黒い画面が出て「セットアップが終わりました」と表示されれば成功です。
   初回は数分かかります。

4. **「2_設定ファイルを作る.bat」をダブルクリック**し、
   勤務割当表の Excel を黒い画面にドラッグして Enter を押します。

   `config\roster.yaml` ができます。中身をメモ帳で開き、
   **対象者と月ごとの回数**を実際のものに直してください。
   （勤務表から検出した氏名がそのまま入るので、対象外の人がいれば消します）

   > このファイルには氏名が入ります。**メールで送ったり共有フォルダに置いたりしないでください。**

### 毎月の作業

**「3_待機表を作る.bat」に、勤務割当表の Excel をドラッグ＆ドロップ**するだけです。
（ダブルクリックしてから、黒い画面にドラッグしても同じです）

先に決めておく担当があれば、聞かれたときに入力します。無ければ Enter だけ押してください。

```
待機の指定: 5=担当B 12=担当C
予備の指定: 5=担当C
```

3つの表が **`ダウンロード\待機表\`** に保存されます。

- `待機表_YYYYMM.xlsx`
- `予備待機表_YYYYMM.xlsx`
- `個人別待機表_YYYYMM.xlsx`

黒い画面に「確認事項」が出た場合は、目を通してください。表は作成されています。

---

## Mac の場合

`mac` フォルダの中の

1. **「セットアップ.command」をダブルクリック**（1回だけ）
2. **「設定ファイルを作る.command」をダブルクリック**（1回だけ）
3. 毎月 **「待機表を作る.command」をダブルクリック**

「開発元を検証できないため開けません」と出たら、
そのファイルを **右クリック →「開く」** を選び、確認画面で「開く」を押してください
（初回だけの操作です）。

---

## 困ったとき

| 出たメッセージ | 対処 |
|---|---|
| Python が見つかりません | Python を入れ直し、「Add python.exe to PATH」にチェックを入れる |
| 先に「1_セットアップ.bat」を実行してください | 手順どおり 1 → 2 → 3 の順に実行する |
| ファイルが見つかりません | 勤務表をドラッグし直す。ファイル名に `"` が入っていないか確認 |
| 部品の取得に失敗しました | インターネットに繋がっているか確認。社内ネットワークの制限がある場合は情報部門へ |
| 対象年月を判別できませんでした | 勤務表の表題に「2026年10月」が入っているか確認。無ければ担当者に相談 |
| 見慣れない記号がありました | 新しい勤務記号です。意味を設定に追加する必要があります |

黒い画面は、閉じるときは右上の × か、`pause` で止まっているときは Enter を押します。

## 保存先を変えたい

`config\roster.yaml` の末尾のほうにある `output:` の `directory:` を書き換えます。

```yaml
output:
  directory: "~/Downloads/待機表"          # 既定
  # directory: "//サーバ名/共有/臨床工学科/待機表"   # 共有フォルダに出す例
```

---

## 個人情報について

- **氏名が入るのは `config/roster.yaml` と `config/history.json` の2つだけ**です。
  どちらもリポジトリには入らない設定（`.gitignore` 済み）にしてあります。
- 作成した待機表そのものにも氏名が入ります。取り扱いにご注意ください。
- プログラム本体・説明書には、実在の氏名は入れていません（担当A〜H という仮名を使っています）。
