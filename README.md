# PULSE TAP

音楽と映像に合わせてタップするブラウザ向けリズムゲーム。

## 特徴

- Web Audio API によるシンセサイザーでロック / ポップス調の楽曲を
  その場で完全合成（外部の音楽・映像ファイルを一切使用しないため著作権フリー）
- 演奏データ（音）と譜面（タップノーツ）を同一のパターンデータから生成しているため、
  音楽と譜面が完全に同期する
- 楽曲のビートに反応するジェネラティブな背景ビジュアル（映像の代わり）
- 4レーン（キーボード `D` `F` `J` `K` / タッチ対応）
- Perfect / Great / Good / Miss judgement、コンボ、スコア、ランク判定
- 収録曲
  - **RED IGNITION**（ROCK, BPM 148）
  - **CANDY SKYLINE**（POPS, BPM 124）

## 遊び方

`index.html` をブラウザで開くだけで起動します（ビルド不要）。
ローカルサーバー経由での起動を推奨します。

```bash
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

曲を選択 → カウントダウン後に自動で楽曲が再生されるので、
判定ラインにノーツが重なったタイミングで対応するレーンのキー（`D` `F` `J` `K`）を
押す、またはタップする。

## ファイル構成

```
index.html         画面構成（タイトル / ゲーム / リザルト）
css/style.css       スタイル
js/audio-engine.js  Web Audio によるシンセサイザー（打楽器・ベース・リード合成）
js/songs.js         楽曲データ定義（BPM・コード進行・パターン → 音声イベント & 譜面を生成）
js/visualizer.js     楽曲のビートに反応する背景ビジュアル
js/game.js          ゲームループ・判定・スコアリング
js/main.js          画面遷移・入力配線
```

## 楽曲を追加する

`js/songs.js` の `rockDef` / `popDef` のようなオブジェクトを追加し、
`buildSong()` に渡して `SONGS` 配列に加えるだけで新曲を追加できる。
BPM・コード進行・各パート（kick / snare / bass / lead）の16分音符ステップパターンを
指定すると、音声とタップ譜面が自動的に同期して生成される。
