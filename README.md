## PCI/EVT時確認薬剤辞書

PCI(経皮的冠動脈インターベンション)・EVT(血管内治療)実施前の問診・
持参薬確認等で使用する、抗血小板薬・抗凝固薬・抗脂質異常症薬の辞書。
辞書本体(薬剤マスタ)はPCI/EVT共通で、確認すべき区分の切り方だけが異なる。

- データ: `data/pci_drug_dictionary.json`
  - 薬剤ごとに一般名・商品名(配合剤を含む)・分類を収録
  - 配合剤は `is_combination` / `components` で構成成分を確認できる
  - `pci_check_bucket`: PCI時確認の15区分(配合剤は複数該当)
    - アスピリン / クロピドグレル / プラスグレル / チカグレロル / その他の抗血小板薬
    - ワルファリン / DOAC / その他の抗凝固薬
    - スタチン(高強度) / スタチン(非高強度) / エゼチミブ / ベンペド酸 / エボロクマブ / インクリシラン / その他の抗脂質薬
    - 高強度スタチンはアトルバスタチン・ピタバスタチン・ロスバスタチン、非高強度スタチンはプラバスタチン・シンバスタチン・フルバスタチンとして分類
  - `evt_check_bucket`: EVT時確認の7区分(抗脂質異常症薬は対象外)
    - アスピリン / P2Y12阻害薬 / チエノピリジン / シロスタゾール / その他の抗血小板薬
    - ワルファリン / DOAC
    - クロピドグレル・プラスグレル・チクロピジンは「P2Y12阻害薬」と「チエノピリジン」の両方に該当
- 検索ツール: `scripts/lookup_drug.py`
  - 商品名または一般名(部分一致)で検索し、該当情報を表示
  - `--mode pci`(既定)/ `--mode evt` でモードを切り替え
  - 該当がない場合は「該当なし」と表示

### 使い方

```bash
# 単発検索(PCIモード、既定)
python3 scripts/lookup_drug.py プラビックス

# EVTモード
python3 scripts/lookup_drug.py プレタール --mode evt

# 対話モード
python3 scripts/lookup_drug.py --mode evt
```

### 注意事項

本辞書は一般的な薬学知識に基づき作成した参考資料であり、医薬品の完全な
網羅性・最新性を保証するものではありません。臨床使用にあたっては必ず
最新の添付文書・インタビューフォーム・院内マニュアル等で確認してください。
