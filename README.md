# taiki — PSVTアブレーション 用語・メモ帳

PSVT(発作性上室性頻拍)アブレーションに関する検索・メモをまとめるための、ブラウザだけで動く個人用メモツールです。サーバーは不要で、`index.html` を開くだけで使えます。

## 使い方

1. `index.html` をブラウザで開く（ダブルクリックでOK）。
2. 上部のタブで機能を切り替える。
3. 入力内容はこの端末のブラウザ内（localStorage）に自動保存される。

## 機能

- **① 用語辞書**: わからない用語とその解説を登録・検索できる辞書。用語名・読み・分類・解説・関連用語・メモを記録し、あとから自由に編集・削除できます。
- **② RMCメモ**: RMC(ポリグラフ)の設定・操作を「基本設定」「フィルタ設定」など大項目ごとに記録するメモ。大項目は自由に追加でき、各項目はあとから修正・追記できます。
- **③ 自分用メモ**: 手技の流れや気づき、合併症対応などを大項目ごとに記録する自分用メモ。項目は編集画面から別の大項目へ移動でき、大項目自体も自由に増やせます。
- **気になるメモ**: とりあえず気になったこと・調べたいことを書き留めておく場所。わかったら「用語辞書」または「RMCメモ／自分用メモ」の好きな大項目に記録するか、不要であれば削除します。
- **データ管理**: 現在のデータをJSONファイルとして書き出し（バックアップ・Gitでの版管理用）、または読み込んで復元できます。

## データの取り扱いについて

このツールは個人の学習・業務メモ用です。患者個人を特定できる情報（氏名・ID・生年月日など）は入力しないでください。誤って個人情報を含む内容が見つかった場合は速やかに削除してください。
